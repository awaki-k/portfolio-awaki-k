# Quantized CNN models (HLS-QCNN)

## 概要
本プロジェクトは、量子化対応訓練（Quantization Aware Training, QAT）を適用した畳み込みニューラルネットワーク（CNN）を、HLS（High-Level Synthesis）でハードウェア実装向けに最適化したものです。主にFPGAやASICなどリソース制約下での推論用途を想定しています。

---

## 背景・動機
- CNNは自動運転、画像認識、医療画像解析、AI支援技術などで広く活用されていますが、**計算資源の消費が大きく、組込みシステムではボトルネック**となることが多いです。
- QATを活用することで、**モデルの精度をほとんど犠牲にせずパラメータサイズと演算量を削減**し、ハードウェア実装時の効率を大幅に向上させます。

---

## 目的
- QATを適用したCNNをHLS設計フローでRTL化し、従来のCPU実装よりも**高速・省資源な推論回路**を構築する。

---

## アーキテクチャ

- **入力**: 28x28 グレースケール画像 (int8)
- **出力**: 手書き数字（0～9）の分類
- **ネットワーク構成**:  
  Conv2D → ReLU → MaxPooling → Conv2D → ReLU → MaxPooling → Flatten省略 → 全結合 → Argmax

---

## 最適化アプローチ

- **QATによる量子化**: モデルサイズと演算量の削減
- **HLSによるRTL生成**:  
  - SystemCでモデリングしStratus HLSでRTL化
  - ループアンローリング（Unroll）、パイプライン化（Pipeline）などを用い**遅延・スループットを最適化**
- **Flatten層省略**: ハードウェア効率向上のため全結合層で直接インデックス指定
- **マイクロアーキテクチャ最適化**:  
  - パイプラインとアンローリングの組み合わせにより、遅延制約内でスループット最大化を目指す
